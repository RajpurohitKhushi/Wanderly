# ✈️ Wanderly — Travel Landing Page UI/UX Design

> **The World Is Waiting for You.**  
> A modern travel-planning landing page designed to inspire exploration through a clean, engaging, and user-friendly interface.

## 🌍 About the Project

**Wanderly** is a travel landing page UI/UX project created to make exploring destinations and planning trips feel simple and enjoyable. The design combines an inviting visual style, clear content hierarchy, and intuitive interface elements to create a welcoming travel experience.

The project focuses on landing page design, design systems, reusable UI components, responsive layout concepts, and frontend implementation.

## ✨ Key Features

- **Hero Section** — An engaging introduction with a clear headline and call-to-action.
- **Destination Exploration** — Visual destination cards to inspire users to discover new places.
- **Travel Planning Interface** — A search-style section for exploring travel options.
- **Why Choose Wanderly** — Highlights the benefits of using the travel platform.
- **Call-to-Action Section** — Encourages users to begin planning their next trip.
- **Consistent Visual Design** — A coordinated color palette, typography, spacing, and component styling.
- **Responsive Design Concepts** — Layouts planned for desktop, tablet, and mobile screens.

## 🎨 Design System

Wanderly uses a warm, minimal visual identity inspired by travel, comfort, and exploration.

| Design Element | Description |
|---|---|
| Primary Color | Deep Teal |
| Background Color | Warm Cream |
| Accent Color | Coral |
| Heading Typography | Epilogue |
| Body Typography | Inter |
| Design Style | Modern, minimal, travel-focused |

### Design Principles

- Clear visual hierarchy and readable typography
- Consistent spacing and alignment
- Reusable interface components
- Simple navigation and clear calls-to-action
- Responsive layout considerations
- Balanced use of color and imagery

## 🧩 Figma Design Boards

The project includes five design boards:

1. **Landing Page** — Main Wanderly website interface.
2. **Design System & Foundation** — Color palette, typography, spacing, and design foundations.
3. **Master Component Library** — Buttons, inputs, cards, and other reusable UI elements.
4. **Responsive Layouts & Breakpoints** — Desktop, tablet, and mobile layout concepts.
5. **Implementation & Technical Specification** — Implementation notes and responsive design specifications.

## 🛠️ Tools & Technologies

- **Google Stitch** — AI-assisted initial design and HTML generation.
- **Figma** — UI/UX design boards, design system, component library, and responsive layouts.
- **HTML** — Website structure.
